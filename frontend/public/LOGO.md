# ITM University logo assets

| File | Use |
| --- | --- |
| `itm-university-logo-vertical.svg` | Stacked maroon logo (login, chat, headers) — matches official ITM branding |
| `itm-university-logo.png` | Horizontal banner from ITM official CDN (optional compact use) |

To use your own exact PNG from the university, replace `itm-university-logo-vertical.svg` or add `itm-university-logo-vertical.png` and update `ITM_LOGO_VERTICAL_SRC` in `src/theme.js`.
